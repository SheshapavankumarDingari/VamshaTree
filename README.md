# VamshaTree 🌳

VamshaTree is an enterprise-grade genealogical and in-story family tree exploration engine rooted in Indian and global historical/mythological contexts. It leverages open-source CC0 Wikidata extraction, private vault caching, and strict trust & safety guardrails.
